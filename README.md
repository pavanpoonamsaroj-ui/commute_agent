# 🚗 AI Commute & Traffic Agent

An interactive web application built with **Streamlit** that fetches live traffic data via the Google Maps API, analyzes it using **Google GenAI (Gemini)**, and generates a structured travel strategy that can be automatically dispatched via WhatsApp.

## 🚀 Features
* **Live Traffic Analysis:** Pulls real-time route and traffic information between any origin and destination.
* **AI Travel Strategies:** Uses Gemini to evaluate roadblocks, travel times, and provide smart transit recommendations.
* **Streamlit Web UI:** Clean, user-friendly interface to input route details and phone numbers on the fly.
* **Automated Dispatch:** Integrates WhatsApp automation to send out travel briefings instantly.

## 🛠️ Tech Stack
* **Python**
* **Streamlit** (Web Framework)
* **Google GenAI SDK (`google-genai`)**
* **Google Maps Directions API**
* **PyWhatKit / Pyperclip** (Automation)
